# Contributing

Thank you for contributing to the IT Support Ticket AI Native project.

## Local setup

1. Ensure Java 22 is installed.
2. Ensure Maven is installed.
3. From the repository root, run:

```bash
mvn clean test
```

## Workflow

- Keep changes small and scoped to the task.
- Prefer documentation and configuration updates before backend business logic.
- Do not commit runtime SQLite files.
- Ensure frontend builds are verified when frontend code changes.

## Pull requests

- Provide a clear description of the change.
- Include verification commands and results.
- Reference related issues or requirements where applicable.
